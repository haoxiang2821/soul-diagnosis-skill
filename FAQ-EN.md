## Installation

**Q6. What do I need?**
ChatGPT **Plus/Pro** (with Codex), network access to GitHub & ChatGPT, and a GitHub account. No coding or local installation.

**Q7. Can I use it without ChatGPT Plus?**
No. Importing MCP Skills is currently a Plus/Pro feature. Try the free lite version first.

**Q8. Step-by-step installation?**
1. Register & log in to GitHub. 2. Open the private repo link I authorized. 3. In Codex, find the "MCP / Skill import" entry. 4. Paste the repo address (e.g. https://github.com/yourname/repo.git). 5. Click import and wait until the skill name appears. 6. Test with a trigger keyword.

**Q9. Import fails?**
Check in order: (1) logged in & can open the private repo (if not, permission issue — contact me); (2) address complete including .git; (3) log out of Codex and back in; (4) change network; (5) screenshot the error and send it. Most failures are network-related.
